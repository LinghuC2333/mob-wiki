## 入口和红点

我的页头像下方是 Tasks 和 Login bonus 两张等宽卡片，标题加动态描述，去掉原来的黄色角标。Invite friends 收进任务列表。商店页不加任务入口。

Tasks 的描述按顺序取第一条，有奖励可领时显示 Claim 加合计，隐藏邮箱未绑定时显示 Link email +500，然后是推荐任务或每日任务的短名加奖励，都做完了显示 Today's tasks done。Login bonus 今天有可领的显示 Claim 加合计，领过了显示 Tomorrow 加下一次的数额。

红点只出现在 me tab 和 Tasks 卡片。有可领奖励时一直亮。隐藏邮箱未绑定时，打开任务列表后当天不再亮，连续亮 7 天后停止。每日任务没做完不亮。

## 任务列表

页面从上到下是推荐、每日、邀请、里程碑、社区。推荐区第一版只显示 1 条，优先级是隐藏邮箱的绑定任务、打完第 1 集、邮件订阅、下一个里程碑、当天的每日任务。任务上线后开始计数，不回溯历史，完成状态以后端记录为准。

| 分区 | 任务 | 奖励 |
|---|---|---|
| 推荐 | 绑定邮箱（隐藏邮箱用户）或订阅更新（真实登录邮箱用户） | 500 |
| 每日 | 签到（显示当日数额）、打完 1 集、掷骰 1 次、Remix 或聊天 1 次 | 不含签到每天 400 |
| 邀请 | 邀请朋友、填邀请码 | 每位朋友最多 3,000，填码 1,000 |
| Stories | 打完 1 / 3 / 5 集、点赞作品、第二部作品打完 1 集、打到结局 | 400 / 600 / 1,000 / 200 / 600 / 1,000 |
| Dice | 第一次掷骰、成功 3 次、失败 3 次、重投 1 次、直接通过 1 次 | 200 / 400 / 200 / 200 / 200 |
| Characters | 关注角色、动态互动、第一条消息、打开主动消息、用 Moons 送礼、订阅角色 | 200 / 200 / 400 / 200 / 500 / 2,000 |
| Remix 和 Dreams | 第一次 Remix、完成 3 次 Remix、进入梦境 | 400 / 600 / 400 |
| 社区 | Discord、Instagram、TikTok、X | 1,000 / 各 200 |

里程碑全做完 9,900，占最小包 495%。按 327 位注册用户的到达人数估算，平均每人约拿 300。第一版不放好评换 Moons，也不放次日回来。

## 绑定邮箱和邮件订阅

拿到的邮箱用来发新故事更新和召回，这是营销邮件，要有同意说明和退订。

10-28 以来注册的 327 人里，隐藏邮箱 143 人（44%）走绑定，真实登录邮箱 161 人（49%）走一键订阅，其余主要是游客。两条任务每个账号只会看到一条，奖励都是 500。

Apple 用户现在绑不了邮箱。Apple 给的邮箱登录时就记成账号邮箱，客户端不打开绑定页，后端也拒绝绑定另一个邮箱。这个任务要后端先放开，建议新邮箱单独存为联系邮箱，不替换 Apple 登录身份。

现行隐私政策写明第三方账号数据只用于登录和账号相关用途，也没有写营销邮件。一键订阅和营销邮件都要等隐私政策更新、法务确认后才能上。后端现在也只有发验证码的能力，退订和批量发送要另外做。

## 邀请

参考 Tipsy，但保留打完一集才发奖。Tipsy 填码就发，Reddit 上已经有版主让自动审核先删帖再复核，也有人说发码的是机器人账号。

| 规则 | 内容 |
|---|---|
| 填码时限 | 注册后 48 小时内 |
| 发奖时限 | 注册后 7 天内，只认填码后首次打完的正式集 |
| 被邀请人 | 打完一集得 1,000 |
| 邀请人 | 朋友打完一集得 1,000，朋友另一天再打完一集得 2,000 |
| 上限 | 邀请人每月最多从 10 位朋友拿奖 |
| 达人码 | 被邀请人得 2,000，邀请人不受上限限制 |

分享从只能复制改成系统分享，弹层显示已邀请人数和已得 Moons。

现行规则是注册 7 天内填码，双方各 20，邀请人再得 20（现行单位）。后端 main 里 `inviterMoonsAfterFiveEpisodes` 的 8 是旧逻辑。

## 埋点和基线

沿用 v1.1 的通用事件 `surface_presented`、`surface_clicked`、`reward_claim_attempt`、`reward_claim_result`，`claim_kind` 为 `task`，`reward_id` 为任务 ID。`virtual_currency_granted` 的 reason 增加 `task` 和 `referral`。

| 行为 | 327 人里已做到 |
|---|---|
| 掷过骰 | 76 |
| 打完 1 / 3 / 5 集 | 55 / 24 / 9 |
| Remix | 26 |
| 和角色聊过 | 7 |
| 送过礼 / 订阅 | 1 / 0 |

数据截至 2026-11-04，未排除内部测试账号。关注角色、动态互动、主动消息、进入梦境和邀请使用量现在都查不到。

## 还没定的事

- 营销邮件的合规做法，以及登录邮箱能否用于营销。
- 发营销邮件的系统，这不在这一版范围内。
- 后端任务系统怎么做，现有成就系统能否复用，以及部分任务的完成判定来源。
- 入口描述由后端下发还是客户端计算。
- 规则切换时老邀请怎么算，达人码怎么发。
- 奖励数额依赖 Moons 100 倍方案。
