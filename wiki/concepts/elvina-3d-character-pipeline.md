# 可动 3D 角色制作流程（Elvina 实践，Tripo + Blender）

把 Lunaverse 角色立绘做成能在广告镜头里动的 3D 角色，2026-10-26 至 10-27 用 TLP 的 Elvina 跑通。做法借原神的制作方法，分部件建模，头发和裙摆有摆动骨头，能换表情。画风保持我们自己的立绘，不改成原神风。飞书原文带全部验收截图和试片，见 https://xcn662409uz0.feishu.cn/docx/GmFEdcdUgolpV6xf0KYc78Dunfe ，文字副本 [source](../../raw/2026-10-27-elvina-3d-character-practice.md)。

## 结论

- 身体用 T 字站姿出图，在 Tripo 里一次分部件生成。骨架在 Blender 里手搭，Studio 的自动绑骨骼对长裙不可用。
- 每种表情先单独生成一颗头，标准成本 75 积分（HD 带贴图 55，重贴图 20）。成片只保留一颗头，其他表情只把嘴周围一小块的颜色、法线和形状烘到这颗头上，用一个 0 到 1 的滑杆切换。换表情时眼妆、腮红、耳环、头发都不动。
- 每次付费生成后先自己对照输入图看正、侧、背和白模，有一处不对就判不合格并写修法。

两颗头直接切换不能用。两次生成的睫毛画法、腮红深浅、耳环位置都不同，切过去像换了一个人，叠化也遮不住。

## 流程

| 步骤 | 做法 | 合格标准 |
|---|---|---|
| 身体 | T 字站姿，双臂水平，袖子不碰裙子，长发放身后；正左右背多视图走 Generate in Parts（60 积分） | 胸口、裙侧没有破洞。Tripo 不给被遮挡处建模 |
| 骨架 | Blender 手搭 Mixamo 命名骨架，头发 4 串、裙摆 8 串摆动骨头，6 秒原地循环待机 | 动画中间帧发尾干净，没有残片 |
| 表情输入图 | Studio 对正面图点 Edit（Nano Banana，0 积分），提示词只改表情，其余逐项写保持不变；再出多视图（0 积分） | 和上一颗头的多视图并排，构图、发长、耳环对得上，否则免费重出 |
| 生成头 | HD 带贴图 55 积分；然后到 Texture 面板关 Remove Lighting、选 4K 重贴图 20 积分 | 生成时顺带的贴图会丢腮红、皮肤发白，所以重贴图必做 |
| 验收 | 输入多视图和正面、侧前、侧面、背面、另一侧、白模拼一张对照图 | 发色、肤色腮红、五官、配饰、发型全部一致 |
| 推进 Blender | DCC Bridge 的 Send to 要人手点；导入后立即另存，插件会删源文件；`slim.py` 只留这颗头（约 600M 降到 75M） | 源模型单独存档 |
| 装头 | 按眼距和眼到嘴距离缩放，眼睛中点对齐、鼻尖对深度；减面到 10%（194 万面到约 14 万面）；下巴下 3 厘米平切，切口以下只留头发，脖子边缘限距离贴合到身体；从旧头传权重 | 只缩放平移，不改脸形 |
| 发色 | 按颜色和位置算头发范围（嘴周围按位置排除），HSV 往下调，直到同灯光下头发渲染中位数和立绘一致（饱和度 0.62、亮度 0.44） | 微笑头系数饱和度乘 0.73、亮度乘 0.82；平静头 0.72、0.85、色相减 1 度 |
| 合并表情 | 见下一节 | 表情 = 0 和 = 1 的六个角度，除嘴以外完全一致 |

## 一颗头换表情的做法

1. 对位。用额头、鼻子、脸颊、下巴的正面皮肤点做带缩放的 ICP（Umeyama 解，剔除离群点），避开嘴。用嘴定位不行，两种表情嘴形不同。贴合后表面差距中位数约 0.4 毫米。
2. 烘焙。在主头嘴周围划一个椭圆，Elvina 的世界坐标中心 x −0.005、z 0.868，横向半径 0.027、纵向 0.013，内圈 72% 全权重，外圈 smoothstep 渐变，只取正面。用 Cycles 选中到活动，把新头的颜色（DIFFUSE color）和法线（tangent）烘到主头 UV 上，cage 0.003、射线距离 0.008、margin 8。
3. 形状。主头加一个形态键，把嘴部顶点投到新头表面，最大移动约 1.2 毫米。
4. 开关。骨架 `Elvina_rig` 的自定义属性「表情」（0 到 1）同时驱动形态键、颜色混合、法线混合。0 平静，1 微笑，打两个关键帧就是平滑过渡。

法线必须和颜色一起换。只换颜色时，主头法线贴图里刻着的笑纹会在平静嘴角外透出一道上扬细纹。

## 坑

- 上贴图开着 Remove Lighting，头发变成又艳又平的正红，腮红消失。关掉的代价是高光烘进贴图，转头时不跟灯走。
- Blender 验收渲染用影棚 HDRI 时脸上有白条、鼻头发亮，像模型坏了。改用均匀白光加一盏柔光，调色用 Khronos PBR Neutral。
- Blender 命令行渲染用 `/Applications/Blender.app/Contents/MacOS/Blender -b 文件 --python 脚本 -- 参数`，多个 `--python` 可以串起来，先设表情再渲染。

## 成本

出图、Edit、多视图 0 积分（会员每月 100 次免费）。HD 带贴图 55，不带贴图 30。重贴图 20。身体分部件生成标价 60，不能同时出贴图。Blender 里的步骤全在本机，不花钱。Elvina 表情阶段实际花了 205 积分，微笑头 130（第一版眼睛和耳环不对白花 55），平静头 75。

## 遗留问题

- 项链两侧脖子边缘近看有毛边，下颌和侧颈有烘进贴图的灰色阴影。
- 头发只到肩胛骨，底边被切平。生成头时输入图只截到胸口，要长发得重新生成一颗长发的头。
- 头相对身体偏小，全身远景里脸显小。放大免费，但脖子接缝要重调。
- 平静表情用的是微笑头的眼睛。
- 这套做法做不了口型。角色要说台词，得在写脚本前另定方案。

## 文件

本机 `Lunaverse AppStore Promotion/Tripo 建模/Elvina/` 下。主文件 `elvina_v6_expressions.blend`（身体、骨架、待机动画、合并后的头和表情滑杆），源模型 `源模型_微笑头.blend`、`源模型_平静头.blend`，对位和发色参数 `装头对位参数.json`，脚本按流程分 `脚本/0_身体骨架` 到 `脚本/5_渲染` 六组，各步骤验收图在 `表情头_v1/`、`平静头_v1/`、`装头_v1/`、`发色_v1/`、`表情切换_v1/`。
